# AI Assistant для STE Slicer

Плагин для STE Slicer 7.10 (Stereotech, форк Cura 3.6). В слайсер встраивается чат с ИИ-агентом: вы описываете задачу печати, прикладываете модель или ТЗ, а агент сам настраивает печать и нарезает модель.

Команда **HandBloodы**, кейс Stereotech на хакатоне «Открой.Моспром».

## Что умеет агент

- выбирает режим печати: **3D** (`classic`), **5D** (`cylindrical_full`) или **5D Spiral** (`cylindrical`);
- подбирает материал по инженерным требованиям из ТЗ, профиль и ключевые настройки;
- анализирует геометрию, ориентирует модель и расставляет её на столе;
- запускает слайсинг, сохраняет проект `.3mf` и G-code, проверяет G-code;
- объясняет каждое решение в формате «параметр → значение → почему».

## Установка и настройка

Подробная инструкция лежит в [plugin/README.md](plugin/README.md). Коротко:

1. Скопируйте папку `plugin/AIAssistant` в папку плагинов STE Slicer.
2. Перезапустите слайсер и откройте пункт **AI Assistant**.
3. В настройках LLM укажите URL, ключ и модель.

## Структура репозитория

```
plugin/
├── README.md                 установка и настройка
└── AIAssistant/
    ├── AIAssistant.py        точка входа плагина
    ├── dock.py               боковая панель чата
    ├── plugin.json           манифест плагина (api 5)
    ├── web/                  интерфейс чата: HTML, CSS, JS
    └── agent/                агент и всё, что он вызывает
        ├── agent.py          цикл диалога с моделью
        ├── llm_client.py     клиент OpenAI-совместимого API
        ├── mcp_server.py     MCP-сервер (JSON-RPC 2.0)
        ├── tools.py          инструменты, которые видит модель
        ├── slicer_api.py     вызовы функций слайсера
        ├── geometry.py       анализ геометрии модели
        ├── knowledge.py      материалы и правила печати
        ├── main_thread.py    выполнение действий в главном потоке Qt
        ├── events.py         события для интерфейса чата
        └── certs/            дополнительные корневые сертификаты
```

## Ограничения

- Код работает на Python 3.5, который входит в дистрибутив STE Slicer. Внешние библиотеки не нужны.
- Режим 5D требует лицензии ATSS.
- Ключ LLM хранится только в настройках слайсера, в коде его нет.
