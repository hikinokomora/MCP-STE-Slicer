# AI Assistant для STE Slicer — установка

Плагин добавляет в STE Slicer 7.10 чат с ИИ-ассистентом, который по модели и техническому заданию выбирает режим 3D/5D, материал и настройки, ориентирует модель, нарезает её и сохраняет проект `.3mf` и G-code.

Полная инструкция по использованию — в [README репозитория](../README.md). Здесь — установка в чистый слайсер и проверка, что всё работает.

Команда **HandBloodы**.

## Установка

1. Установите STE Slicer 7.10. Для режимов 5D активируйте лицензию ATSS.
2. Закройте слайсер.
3. Скопируйте папку `AIAssistant` из этого каталога в папку плагинов пользователя:

   ```
   %APPDATA%\steslicer\7.10\plugins\AIAssistant
   ```

   Папку конфигурации можно открыть из слайсера: **Справка → Показать папку конфигурации**, затем `plugins`. Внутри должен оказаться файл `AIAssistant\plugin.json`.
4. Запустите STE Slicer. В меню появится пункт **AI Assistant** с командами:
   - **Открыть чат**;
   - **Настройки LLM**;
   - **Папка результатов**.

Устанавливать Python и библиотеки не нужно: плагин использует то, что уже есть в слайсере (Python 3.5, PyQt5, numpy).

## Настройка URL и ключа LLM

1. **AI Assistant → Настройки LLM**. При первом запуске окно настроек откроется само.
2. Укажите:
   - **Base URL** — OpenAI-совместимый API, например `https://api.timeweb.ai/v1`;
   - **API key** — ключ доступа;
   - **Модель** — например `dashscope/qwen3.8-flash`. Модель должна поддерживать вызов инструментов (tool calling).
3. Нажмите **Проверить связь** — должно появиться «LLM отвечает за N с». Затем **Сохранить**.

Ключ хранится в настройках STE Slicer (`steslicer.cfg`, раздел `ai_assistant`) и не попадает в файлы плагина.

Сертификаты HTTPS проверяются по хранилищу Windows, по набору слайсера и по файлу `AIAssistant/agent/certs/extra_roots.pem`. В файле лежат публичные корневые сертификаты, которых нет в старом наборе слайсера (например, GlobalSign Root R46 для `api.timeweb.ai`). Если LLM-сервер подписан другим новым корнем, добавьте его PEM в этот файл.

## Проверка после установки

1. **AI Assistant → Открыть чат.** Окно чата откроется панелью поверх правой части слайсера (через Microsoft Edge в режиме приложения). Если Edge нет, чат откроется в браузере по умолчанию по адресу `http://127.0.0.1:8765/`.
2. Напишите «Что сейчас настроено в слайсере?». Ассистент должен вызвать `get_scene_info` и назвать принтер, режим, профиль и материал.
3. Перетащите в чат STL-модель и напишите, например, «Кронштейн под нагрузку, PETG, без поддержек». Ассистент загрузит модель, настроит, нарежет и сохранит `project.3mf` и `result.gcode` в `Документы\STE Slicer AI Results\<имя модели>\`.

## MCP-сервер

Плагин сам является MCP-сервером (JSON-RPC 2.0 поверх HTTP): `POST http://127.0.0.1:8765/mcp`. Поддерживаются методы `initialize`, `notifications/initialized`, `ping`, `tools/list`, `tools/call`. Эти же 28 инструментов ассистент передаёт в LLM. Описание каждого — в [справочнике инструментов](../README.md#справочник-инструментов).

```bash
curl -s -X POST http://127.0.0.1:8765/mcp -H "Content-Type: application/json" -d "{\"jsonrpc\":\"2.0\",\"id\":1,\"method\":\"tools/list\"}"
```

## Если что-то не работает

- **Нет пункта AI Assistant.** Проверьте путь `%APPDATA%\steslicer\7.10\plugins\AIAssistant\plugin.json` и перезапустите слайсер.
- **Ошибки в логе.** Лог слайсера: `%APPDATA%\steslicer\7.10\steslicer.log`, строки `AIAssistant`.
- **Слайсер завис.** Откройте `http://127.0.0.1:8765/api/debug/threads` — там стеки всех потоков, страница отвечает даже при зависшем интерфейсе. Приложите её к сообщению об ошибке.

Остальные вопросы — в разделе [«Решение проблем»](../README.md#решение-проблем).
